# Food Ordering App - Zomato-like Platform

## Project Overview
A comprehensive food ordering and delivery application with web, mobile, and backend services.

### Tech Stack
- **Frontend**: Angular
- **Backend**: Java (Spring Boot)
- **Database**: Oracle SQL
- **Mobile**: Native iOS/Android
- **Hosting**: AWS

### Features
- User Authentication (Customers & Restaurant Admins)
- Restaurant & Menu Management
- Food Ordering System
- Payment Integration
- Real-time Delivery Tracking
- Order History & Reviews
- Ratings & Feedback System
- Admin Dashboard

### Project Structure
```
Food_Ordering_App/
├── frontend/              # Angular Application
├── backend/              # Java Spring Boot API
├── mobile/               # Native iOS/Android Apps
├── database/             # Oracle SQL Schemas
├── deployment/           # AWS Configuration
├── documentation/        # API & Setup Docs
└── README.md
```
